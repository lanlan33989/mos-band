③ 硬件侧显示「固件已确认」但实物没动 → 硬件问题（接线 / 供电 / 继电器极性）
④ 软件已发但「无固件回显」 → 固件没跑 / COM 号不对 / 被串口监视器占用
⑤ 连字都没有 → ASR / 网络问题（软件侧）
串口下拉框列出的是电脑真实存在的串口（含蓝牙/主板占用的虚拟口）；手环插上后多出来的那个（常见 USB-SERIAL CH340 / CP210x）就是它，选错换一个即可。纯充电线插上不会出现新串口。
