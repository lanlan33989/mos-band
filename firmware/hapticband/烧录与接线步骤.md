# 烧录与接线步骤（M1 · 七个输出版 · 傻瓜版）

> 适用：Windows，Arduino IDE 2.x，**零基础也能照做**
> 配套：同目录 `hapticband.ino` ｜ 仿真：仓库根 `README.md` 与 `docs/Wokwi-导入全指引.md`
> 全程约 60~90 分钟（装软件占大头，接线 20 分钟，烧录 5 分钟）

**做完你会得到**：插上 USB、打开串口监视器，敲 `vib1` 震一下、`strap2` 收紧到 2 档、`cool` 变凉、`warm` 变热——不需要 WiFi、不需要 MQTT、不需要心率模块。

## 1. 装软件（只做一次，约 30 分钟）

### 1.1 装 Arduino IDE 2.x

1. 打开 `https://www.arduino.cc/en/software`
2. 找 **Windows Win 10 and newer**，点下载
3. 双击 `.exe`，一路「下一步 / 我同意 / 安装」，不改任何选项
4. **预期**：桌面出现 Arduino IDE 图标，打开是白色/深蓝窗口，左边一列小图标

### 1.2 装 ESP32 开发板支持包

1. 菜单 **文件 → 首选项**
2. 找到「**其他开发板管理器地址**」，点右边小方框图标
3. 粘贴这一行，点「确定」：

   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

4. 点**左边一列第二个图标**（开发板管理器），或菜单 **工具 → 开发板 → 开发板管理器**
5. 搜 `esp32`，找到「**esp32 by Espressif Systems**」，点「**安装**」
6. **预期**：等 5~20 分钟，最后变成 **INSTALLED**

> 卡住/失败：换手机热点再点安装；网址一个字别改。

### 1.3 装 3 个库

菜单 **工具 → 管理库**，逐个搜下表左列，认准作者，点「**安装**」，弹依赖提示选「**全部安装**」。

| 搜索词 | 认准这一条 |

| `ESP32Servo` | **ESP32Servo** by **Kevin Harrington** |

**预期**：三条都显示 **INSTALLED**。不用装 ArduinoJson、不用装 heartRate.h，固件里自己处理了。

## 2. 接线（照着插，全程不用焊）

**先拔掉 USB，全程断电操作。**

### 2.1 看懂面包板

- 830 孔面包板，中间一条**凹槽**，上下两片孔区
- 最上/最下边缘标 `+`（红线）和 `-`（蓝线）的长条是**电源轨**：整条 `+` 互通，整条 `-` 互通
- 中间孔区：**同一排 5 个孔横向互通**，竖着不互通，跨凹槽不互通
- ESP32 **跨着凹槽**插进去，两排针各占一半

### 2.2 总览（俯视，数字是板上印的引脚号）

 - │ ●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●● │ -轨(GND 全系统共地)

### 2.4 两个继电器怎么让 TEC 又凉又热（关键一步）

TEC 是两线器件，**电流方向决定制冷还是制热**。两个继电器组成换向电路：

```
                 外部 5V+
                    │
        ┌───────────┴───────────┐
        │ (NO)            (NO)  │
   ┌────┴────┐           ┌────┴────┐
   │ 继电器A │           │ 继电器B │
   │ COM     │           │ COM     │
   └────┬────┘           └────┬────┘
        │                     │
     TEC 端1 ───[ TEC ]─── TEC 端2
        │                     │
        │ (NC)           (NC) │
        └───────────┬───────────┘
                    │
                   GND
```

**接法**：两个继电器的 **NO 全部接外部 5V+**，**NC 全部接 GND**，**各自的 COM 分别接 TEC 的一根线**。用鳄鱼夹线或接线端子直接连，TEC 电流大，**不要走面包板细杜邦线**。

| 状态 | 继电器 A | 继电器 B | 结果 |
|---|---|---|---|
| `cool` 凉 | 吸合（端1→5V） | 释放（端2→GND） | 电流正方向，贴皮肤面变凉 |
| `warm` 热 | 释放（端1→GND） | 吸合（端2→5V） | 电流反方向，同一面变热 |
| 关 | 释放 | 释放 | 两端都 GND，无压差 |

- 两个继电器每个模块上都有 `COM` / `NO` / `NC` 三个输出端子（**买的时候确认有这三个**，只有 COM+NO 的做不了「热」）
- 每个模块上一般有颗 LED，`cool` / `warm` 时会亮、会听到「嗒」一声
- TEC 用**导热硅脂/导热双面胶**把一面贴牢**铝散热片**，另一面朝皮肤
- **极性判断**：敲 `cool`，如果贴皮肤那面反而变热 → 把 TEC 两根线对调即可，不用改代码
- 固件每次切换先写「全关」再写目标，机械动作天然错开，**不会短路**

### 2.5 舵机怎么拉表带

1. 魔术贴绑带绕成手腕大小，一端用扎带固定在舵机外壳上
2. 另一端系细尼龙线，线尾缠在摆臂最外侧孔里
3. `strap0` 松开 → `strap1` 35° 微紧 → `strap2` 70° 明显紧，调到不过勒

### 2.6 上电前最后 3 个检查

- [ ] **两个电源正极没有连在一起**：ESP32 走电脑 USB，模块走外部充电头，**只连了 GND 那一根线**
- [ ] 所有 `GND` 都落在同一条 `-` 轨；两个继电器 NO 都接 `+` 轨、NC 都接 `-` 轨
- [ ] MAX30102 接 **3V3**；TEC 贴了散热片

> 接线完成拍一张清晰俯视照片存着，11.8 视频「接线图」镜头和软著用户手册都能复用。

1. 打开 `firmware/hapticband/`，确认是 `hapticband.ino`

## 5. 打开串口，七个输出逐个测

1. 菜单 **工具 → 串口监视器**（或右上角放大镜）
2. 右下角两个下拉：左边 **115200 baud**，右边 **「换行符」/ Both NL & CR**（**必须选，不然敲命令没反应**）
3. 按板上 **EN / RST** 重启

**预期开机日志**：

```
============================================
 触觉社交手环 ESP32 固件  M1  七个输出版
============================================
[初始化] 三通道就绪（震动=关 / TEC=关 / 舵机=松开）
[心率] MAX30102 就绪          ← 或「没检测到」也正常
[WiFi] 跳过联网 / 连上了      ← 两种都正常
-------- 七个输出（输完按回车）--------
  vib1 / vib2 / vib3    振动 1 / 2 / 3 下
  strap1 / strap2       收紧 1 档(35度) / 2 档(70度)
  cool / warm           凉 5 秒 / 热 5 秒（自动断电）
```

### 命令表

| 敲这个 | 串口打印 | 硬件 |
|---|---|---|
| `vib1` / `vib2` / `vib3` | `[动作] 振动 N 下` | 震 1 / 2 / 3 下 |
| `strap1` / `strap2` | `[动作] 表带收紧 -> 舵机 35 / 70 度` | 摆臂转到对应角度 |
| `cool` | `[动作] 凉：TEC 制冷方向通电 5 秒` | 继电器 A 吸合，变凉，5 秒后 `[安全] 温度脉冲 5 秒到，自动断电` |
| `warm` | `[动作] 热：TEC 制热方向通电 5 秒` | 继电器 B 吸合，变热，5 秒后自动断电 |
| `demo` | 七个 `[动作]` 依次打印，最后 `[演示] 七个输出串烧结束，已复位` | 拍视频特写用，约 20 秒 |
| `strap0` | `舵机 0 度` | 松开（维护命令，不属于七个输出） |
| `off` | `[动作] 温度通道关闭` | 关温度（维护命令） |
| `status` | WiFi / MQTT / 心率 / 舵机角度 / 温度状态 | — |
| `{"act":"cool"}` | 与 `cool` 完全一样 | PC 侧流水线就用这个格式 |

**心率**：手指轻压 MAX30102 黑色小窗 3~5 秒，敲 `status`。出数字正常；一直 `-1` 也正常（`wrist/bio` 如实上报 -1），不影响 M1 验收。

## 6. 常见故障排查

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 串口乱码 | 波特率不对 | 改 **115200** |
| 敲命令没反应 | 行尾没选换行符 | 右下角选「**换行符**」，再按 EN 重启 |
| 上传时端口消失 | 纯充电线 / 驱动没装 | 换数据线；装 CP210x 或 CH340 驱动 |
| 编译找不到 `.h` | 少装库 | §1.3 三个库逐个确认 INSTALLED |
| 马达完全不震 | 买成裸马达 / IN 接错 | 必须是「带驱动板的模块」；确认 IN 接 GPIO25 |
| 一震 ESP32 就重启 | 马达取电不够 | 震动模块 VCC 从 `3V3` 改插 `+` 轨（外部 5V） |
| 舵机抖 / 发烫 / 板子重启 | 取电不足或没共地 | 舵机 VCC/GND 走外部 5V；**确认第 3 根共地线接了** |
| 继电器一上电就吸合、`off` 也不松开 | 触发极性反了 / 3.3V 驱动 5V 模块关不断 | ① `RELAY_ACTIVE_LOW 1` 改成 `0` 重传；② 还不行把 `RELAY_OPEN_DRAIN 0` 改成 `1` 再传 |
| `cool` 不凉、`warm` 不热 | NO/NC 接反，或 TEC 极性反 | 检查两个继电器 NO 都接 5V+、NC 都接 GND；再把 TEC 两根线对调 |
| 只有凉没有热 | 继电器 B 的 IN 没接 GPIO14，或模块只有 COM+NO | 查第 12 根线；确认模块有 NC 端子 |
| 温度一直不断电 | 不可能（固件 5 秒脉冲） | 敲 `status` 看温度状态；敲 `off` 手动关 |
| 心率一直 -1 | 没检测到模块 / 手指没贴好 | 查 SDA=21、SCL=22、VCC=3V3；**M1 验收不要求它出数** |
| WiFi / MQTT 连不上 | 5GHz / 密码错 / 外网不通 | 忽略即可，串口演示模式照常用 |

## 7.（可选）验证 MQTT 真联通

**M1 验收不要求这一步**。想提前验证：

1. §3 填好 WiFi 重新上传，串口出现 `[MQTT] 连接 broker.emqx.io ... 成功`
2. 浏览器打开 MQTTX 网页版（`https://mqttx.app/`）或装桌面版
3. 新建连接：主机 `broker.emqx.io`，**TCP 端口 1883**（网页版 WebSocket 用 **8083**、路径 `/mqtt`）
4. 发布：主题 `wrist/cmd`，内容：

   ```json
   {"act":"vib3"}
   ```

5. **预期**：串口打印 `[MQTT] 收到指令: ...` 和 `[动作] 振动 3 下`，马达震 3 下
6. 订阅 `wrist/bio` → 每 2 秒一条 `{"ch":"bio","hr":92}`（或 -1）

> 任何能向 `wrist/cmd` 发 `{"act":"..."}` 的东西都能驱动手环，固件不认来源只认动作。

## 8. B 计划 / Wokwi（硬件还没到）

- 这个 `.ino` **可以直接在 Wokwi 里跑**：ESP32 + LED（代替震动/两个继电器）+ Servo + WiFi 都能仿真，MQTT 是真连外网
- MAX30102 在 Wokwi 里没有元件 → 固件打印「没检测到 MAX30102」并上报 `{"ch":"bio","hr":-1}`，**七个输出不受影响**
- 完全断网时：PC 串口直接粘 `{"act":"cool"}` 也能触发
- MQTT 指令与串口命令走同一个 `handleCommand()`，互不阻塞

## 9. 安全红线

1. TEC 必须贴散热片；`cool` / `warm` 是 5 秒脉冲自动断电，另有 30 秒绝对硬限
2. **外部 5V 正极不要接 ESP32 的 VIN/5V 脚**，两个电源只连 GND
3. **共地那根线必须接**
4. 两个继电器的 NO 都接 5V+、NC 都接 GND；切换前固件先全关
5. 不接锂电池；调试时不要戴在手上通电
6. TEC 两根粗线不走面包板细杜邦线
