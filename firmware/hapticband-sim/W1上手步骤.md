## 一、文件放入 Wokwi

**浏览器版（直观，推荐先用这个）**
1. 打开 wokwi.com 注册登录 → New Project → ESP32
2. 左侧 `sketch.ino` 内容整体替换为 `hapticband-sim.ino` 的内容
3. 点右上角下拉箭头 → New Tab，建两个文件：
   - `diagram.json` ← 粘贴本目录 `diagram.json` 全文
   - `libraries.txt` ← 粘贴本目录 `libraries.txt` 全文
4. 点绿色播放键编译运行

**wokwi-cli 版（可无头运行/录屏/挂 CI）**
```
npm i -g @wokwi/cli
# 把本目录三个文件放一个文件夹
wokwi-cli .
```

## 二、网络桥接（MQTT 能否出网的关键）

**2026-11-06 按官方 ESP32 WiFi 指南复核：浏览器版不需要装任何本地软件。** 免费公共网关（Public Gateway）默认开箱即用、支持出网连接（outgoing ✅），MQTT 到 `broker-cn.emqx.io` 直连即可。私有网关（wokwigw.exe）是**付费功能**，只在需要访问本机服务/端口转发时用得到——本项目用不到。官方指南：https://docs.wokwi.com/guides/esp32-wifi

固件已按官方建议显式指定 `WiFi.begin("Wokwi-GUEST", "", 6)`（跳过扫描阶段、省约 4 秒）；公共网关稳定性标为 Medium，因此加了 **20 秒超时 + 每 8 秒自动重连**，一次抖动不会永久离线。

判断通没通：看 Serial Monitor 出现 `[WiFi] 连上了` + `[MQTT] 连接 broker-cn.emqx.io ... 成功` + `[MQTT] 已订阅 wrist/cmd`。若暂时没连上，串口仍可完整演示七个输出与手势（上报显示「MQTT 未连，仅串口」属预期），联网恢复后会自动补上。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| `[WiFi] 20 秒没连上` | 公共网关偶发慢：固件已每 8 秒自动重试，等几秒看是否出现 `[WiFi] 连上了`；也可刷新页面重播。确认 SSID 是 `Wokwi-GUEST`（全大写）、密码留空、diagram 里没有自定义 WiFi AP 元件（有了会顶掉默认网络） |
| `[MQTT] 连接... 失败(-2)` | 多为端点不可达：固件第 1 区 `MQTT_BROKER` 与本机 `config.json` 的 `mqtt.broker` 必须**同为** `broker-cn.emqx.io`（国际端点 broker.emqx.io 在 Wokwi 里连不上）；改完重新编译重跑 |
| 编译报 `MAX30105.h` 找不到 | libraries.txt 第三行没生效；浏览器版确认文件名一字不差 |
| 心率显示 -1 或想看心率 | Wokwi **没有原生 MAX30102 元件**（2026-11-05 已验证：加了会整画布静默加载失败），diagram.json 已默认移除、走模拟心率 62-108；真机版仍走真传感器 |
| 按钮按下没反应 | 正常，W1 只接线不读；W2 手势状态机才启用 |
| 舵机不动 | 看 Serial 是否打印 `[动作] 表带收紧`；打印了但不动 = diagram 里 PWM 线没连上 |

| 手势 | 操作方法（E1-E4 从左到右） | 预期 `wrist/ui` 消息 |
|---|---|---|
| tap1 | 单击任意按钮（30-250ms），**停 2 秒**等静默结算（2026-11-05 改：tap 一律让路 swipe/rub） | `{"ch":"ui","g":"tap1","ms":...}` |
| tap2 | **同一按钮**快速连点两下（间隔 80-350ms），再停 2 秒等结算（所以 tap2 会比动作晚约 2 秒出现，属预期） | `"g":"tap2"` |
| long | 按住 ≥800ms | `"g":"long"` + 串口 `[静音] long -> 静音 10 分钟` |
| long 再来一次 | 静音状态下再长按 | 解除静音 |
| swipe_up | 依次点 E1→E2→E3→E4：**每步 ≤1 秒、总共 ≤3 秒**（2026-11-05 放宽，慢速点按即可） | `"g":"swipe_up"` |
| swipe_down | 反过来 E4→E3→E2→E1，节奏同上 | `"g":"swipe_down"` |
| rub | E1→E2→E1→E2 **交替点 4 次**（1.5 秒窗口内，别快于 0.3 秒、别慢于 2.5 秒）——触发表情屏开心 5 秒 | `"g":"rub"` |

### 表情屏（v1.5）

画布右下的蓝色 OLED 屏默认显示一双**居中**的会眨眼的眼睛。表情来源：

- 六个手势各有表情（tap1 大笑 / tap2 困惑 / swipe_up 兴奋 / swipe_down 困倦 / rub 单眼眨+大笑 / long 闭眼=关机、再长按睁眼）
- AI 自己发七个输出信号时也有表情（vib3 惊讶、strap2 冒汗、cool 害羞、warm 开心……）
- 没人操作时每 6-14 秒自主来一个 0.9 秒小动作，结束立刻回中央
- 串口可直接敲 `happy / laugh / wink / confused / surprised / cyclops / angry / tired / time` 单独验表情
